# Alfred Kerbs localization source

This directory versions the agreed English and French localization layer for the
Alfred Kerbs catalogue embedded by `../index.html`, together with the Innova
Eyewear footer logo used on dark backgrounds.

The paths mirror the source application so the localization can be applied and
reviewed deterministically. The public wrapper remains unchanged and this commit
does not deploy or publish the catalogue.

Source baseline: `a3e186583bc543188ac0eaac84e6a9703c9d5f6e`.
